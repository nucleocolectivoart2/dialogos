# MEDULAR | Diálogos de Regeneración

**MEDULAR** es una infraestructura narrativa, pedagógica y colaborativa diseñada para activar la regeneración biótica y social. Desarrollada por **Núcleo Colectivo (Núcleo Sostenible)** en articulación con **Integricult**, esta plataforma transmedia utiliza el diálogo como eje central para reconfigurar la relación entre los sistemas humanos y los ciclos naturales.

## 🎨 Identidad Visual y Estilo

MEDULAR sigue una estética de **Infraestructura de Alta Gama**:
- **Colores Primarios**: Cian Eléctrico (`#00e1ff`) para la marca y sintonía; Amarillo Solar (`#ffe106`) para acentos técnicos y alertas.
- **Geometría**: Ángulos rectos (`rounded-none`). Se evita el uso de bordes redondeados para proyectar solidez y precisión técnica.
- **Tipografía**: Combinación de Montserrat (Black/Title) para impacto y Alegreya/Cormorant Garamond para profundidad editorial.
- **Navegación**: Barra superior con estilo **Glassmorphism Oscuro** y menú hamburguesa responsivo.

## 🚀 Características Principales

### 1. Ecosistema de Diálogos (Mapa Interactivo)
Una visualización dinámica no lineal que conecta episodios, temas, actores y territorios.

### 2. Podcast Core (Centro Vivo)
El eje estructural accesible mediante un widget integrado de Spreaker en una interfaz técnica flotante.

### 3. Bitácora (Archivo de Saberes)
Un espacio de investigación profunda con estética editorial de precisión.

### 4. Simuladores (Serious Games ESG)
Entornos de toma de decisiones estratégica basados en evidencia con recompensas de XP.

## 🎮 Sistema de Gamificación (XP Protocol)

La plataforma incentiva la curiosidad mediante un sistema de recompensas:
- **Niveles**: El usuario progresa desde *Observador Bótico* hasta *Arquitecto Regenerativo*.
- **XP (Experiencia)**: Obtenida mediante la sintonía de podcasts, lectura de bitácoras y simulaciones.

## 🛠️ Guía de Publicación (IMPORTANTE)

Para evitar errores de build en producción (Error ID: d0a693a9):
- **Todas las rutas en `src/app/` DEBEN estar en minúsculas**.
- Se han eliminado las carpetas en mayúsculas (`ARCHIVO`, `ECOSISTEMA`, `RADIO`) para evitar colisiones en el sistema de archivos case-sensitive de los servidores de build.
